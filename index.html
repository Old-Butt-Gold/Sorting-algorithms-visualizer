    The comparison lab

    Pick two to four algorithms. They get the same array and the same operation budget, so the winner is decided by the algorithm, not by luck. Pause, step and scrub stay in sync for every lane.

    Every algorithm runs on the current array in the background. The table counts real operations, and the note below explains the result instead of just naming a winner.

    Reading the canvas

    • Compare — two candidates are being checked. The pulse is real work, not decoration.
    • Swap — elements exchanged places.
    • Pivot — the value the partition is built around.
    • Locked — this position is final, verified against a sorted copy.
    • Buffer — merge and radix sort use this lane for temporary values or counters.

    Playback speed is measured in operations per second. It changes how fast the log is replayed, never the algorithm's own complexity. The metrics count virtual work; the replay clock is shown separately and recalculates with speed and scrubbing.
